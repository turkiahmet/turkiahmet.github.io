# تنبيهات رسائل الزوار المجانية — تجهيز غير مفعّل

يرسل برنامج Apps Script خاص تنبيهًا عامًا إلى **turkiahmet26@gmail.com** عند وجود رسائل جديدة. يحتوي التنبيه على العدد ورابط اللوحة فقط، دون أسماء الزوار أو عناوينهم أو نصوص رسائلهم. تبقى الرسائل الأصلية في قاعدة D1 الخاصة. لا يرسل ردودًا إلى الزوار.

هذا المسار لا يحتاج نطاقًا مدفوعًا أو بطاقة أو تجربة زمنية أو ترقية. يكفي حساب Gmail شخصي وفق عرض Google الحالي، ضمن الحصص المجانية؛ ولا يوجد ضمان لبقاء سياسات مزود الخدمة دون تغيير. بلوغ الحصة يؤجل التنبيه ولا يستدعي ترقية مدفوعة.

## الحالة والتفويض

- الشفرة محفوظة في المستودع وجاهزة للمراجعة؛ لا يعني وجودها أو نشر مسار الخادم المغلق أن التنبيهات تعمل.
- `EMAIL_NOTIFICATIONS_ENABLED` غير مضبوط افتراضيًا، فيبقى المسار مغلقًا.
- **لا تنشئ مفتاحًا ولا تمنح صلاحية بريد ولا تنشئ مؤقتًا قبل موافقة الباحث المحددة** على تشغيل البرنامج وإرسال التنبيهات إلى بريده.
- لا تستخدم أي كلمة مرور أو مفتاح جلسة أو رمز GitHub قائم لهذا الربط. يلزم مفتاح مستقل عشوائي من ٣٢ بايت على الأقل، بصيغة base64url طولها ٤٣ حرفًا على الأقل، يحفظ في Cloudflare Secret باسم `NOTIFICATION_SECRET` وفي Script Properties باسم `TOKEN`. لا يُحفظ في المصدر أو المحادثة أو الرابط.
- البرنامج خاص ولا يُنشر بوصفه Web App؛ لا توجد نقطة دخول عامة `doGet` أو `doPost`.

## الإعداد بعد الموافقة

1. طبّق الإضافة الموجودة في `admin-backend/migrations/001_contact_notifications.sql` على قاعدة D1 الخاصة نفسها. الإضافة قابلة للتكرار؛ لا تعيد ضبط عداد قائم ولا تنسخ الرسائل أو تحذفها. يبدأ العداد للرسائل الواصلة بعد الإضافة، ولا يعتبر الرسائل القديمة جديدة.
2. انشر Worker المبني من المصدر المراجع. احفظ المفتاح المستقل في `NOTIFICATION_SECRET`، واضبط `EMAIL_NOTIFICATIONS_ENABLED=true` عند اختبار الربط.
3. أنشئ مشروع Apps Script مستقلًا داخل حساب **turkiahmet26@gmail.com** وانسخ `Code.gs` و`appsscript.json`. لا تربطه بمشروع فوترة أو APIs مدفوعة.
4. احفظ قيمة المفتاح في **Project Settings → Script Properties → TOKEN**. لا تكتبها في ملف الشفرة.
5. شغّل `initializeBaseline` مرة واحدة. هذا يثبت العداد الحالي دون إرسال، فتبدأ التنبيهات من الرسالة التالية. تشغيله لاحقًا يتجاوز التنبيهات غير المرسلة عمدًا؛ لا تستعمله علاجًا تلقائيًا للأخطاء.
6. راجع تفويض Google مع الباحث. النطاقان الوحيدان هما `script.send_mail` للإرسال و`script.external_request` للاتصال بخدمة العداد. MailApp لا يقرأ صندوق Gmail. إذا ظهر حظر أو تحذير أمني، سلّم الخطوة للباحث ولا تتجاوزه آليًا.
7. من **Triggers → Add Trigger** اختر `notifyNewVisitorMessages`، ثم **Time-driven → Minutes timer → Every 5 minutes**. أنشئ مؤقتًا واحدًا فقط. لا توجد دالة تنشئ المؤقت برمجيًا؛ وبذلك لا يلزم نطاق `script.scriptapp` الإضافي.
8. أرسل رسالة اختبار من الموقع، وشغّل الدالة، وتحقق من البريد المستلم وصندوق الموقع. يثبت استلام البريد نجاح الإشعار؛ نجاح البناء وحده لا يثبته.

## الحصص والموثوقية

- حصص Google الحالية للحساب الشخصي: **١٠٠ مستلم يوميًا**، و**٩٠ دقيقة تشغيل يومية للمؤقتات**، و**٢٠ ألف طلب URL Fetch يوميًا**. تشترك برامج الحساب الأخرى في الحصص المنطبقة.
- يفحص البرنامج الحصة الفعلية بـ`MailApp.getRemainingDailyQuota()`، ويضع حدًا إضافيًا محليًا قدره **٩٠ تنبيهًا في نافذة ٢٤ ساعة**. يجمع كل الرسائل الجديدة في تنبيه واحد لكل تشغيل، ويؤجل الزائد دون تحريك مؤشر الإرسال.
- الفحص كل خمس دقائق تقريبي وليس إشعارًا لحظيًا مضمونًا. يتأثر بمواعيد Google والاتصال والحصص وأخطاء التنفيذ.
- يفشل الاتصال أو الإرسال دون تحريك `LAST_SEQUENCE`. القفل يمنع تشغيلين متزامنين، والمؤشر يمنع إعادة التنبيه للمجموعة نفسها بعد نجاح حفظه.
- إذا نجح إرسال البريد وفشل حفظ مؤشره، قد يتكرر تنبيه في التشغيل التالي. لا توجد ضمانة إرسال مرة واحدة بالضبط عبر خدمتين مستقلتين. لا تضيع الرسالة الأصلية بسبب ذلك.
- العداد يزيد داخل معاملة حفظ رسالة الزائر نفسها. الرسالة المرفوضة أو حقل مكافحة الرسائل الآلية أو امتلاء الصندوق لا يزيده. الحذف أو الأرشفة لا ينقصانه.
- الإيقاف: عطّل `EMAIL_NOTIFICATIONS_ENABLED` واحذف مؤقت البرنامج من واجهته عند طلب الباحث؛ لا تحذف الرسائل لهذا الغرض.

## حدود الوصول

المسار `GET /api/notifications/summary?after=0` لا يقبل إلا مفتاح التنبيهات في `Authorization: Bearer …`. لا يقبل جلسة المالك بديلًا عنه، ولا مفتاحًا في الرابط، ولا يتيح CORS. يستعمل تحقق HMAC عبر Web Crypto بدل مقارنة نصية متغيرة الزمن. لا يعيد إلا:

```json
{"sequence":12,"pending":2,"latestAt":"2026-11-05T00:00:00.000Z"}
```

لا يمنح هذا المفتاح تحرير الموقع أو قراءة الرسائل أو البريد. يعاد رفض المؤشر الذي يتجاوز العداد؛ يلزم فحص السبب بدل إعادة ضبطه تلقائيًا.
